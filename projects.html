Sarawak Earth Detectives

Hackathon

Sarawak Space Challenge 2026 · Local NASA Space Apps event · “Be An Earth System Trend Detective!” challenge

We built a detective agency game for students. An AI client brings cases about floods, haze, peat fires and dry spells in Sarawak, and students use decades of NASA Earth data to choose evidence, test whether a change is real and write their verdict.

  • React
  • Three.js
  • ECharts
  • FastAPI
  • Google ADK
  • Gemini
  • Google Cloud Run
  • Firebase
  • NASA POWER & GIBS data

Champion, Sarawak Space Challenge · Global nominees for NASA Space Apps Challenge 2026.

StartupBuddy

Hackathon

Dormathon 2026 · Track 2: WorkBuddy Agentic Solutions · October 2026

We built an AI tool to help aspiring Malaysian founders test a business idea and book their first meetings. It checks the idea against Malaysian law, finds nearby competitors, builds a Business Model Canvas for a panel of AI reviewers, and drafts emails and calendar invitations once the founder approves.

  • React
  • TypeScript
  • FastAPI
  • Google ADK
  • Gemini
  • Google Cloud Run
  • Firebase
  • Tencent WorkBuddy
  • Google Maps & Workspace APIs

GuardAgent

Hackathon

Healthcare AI Hackathon · Kuching, Sarawak · August 2026

We built an AI system for elderly care that uses a camera to detect falls in real time. It assesses the fall using the person’s medical history, then calls an ambulance with a spoken briefing, unlocks the door for paramedics and texts the family.

  • Python
  • YOLO pose estimation
  • Google ADK
  • Ollama
  • Gemma
  • Twilio
  • Docker

4th place in the grand final. My first hackathon, and we made it all the way to the final round.
